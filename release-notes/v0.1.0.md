# squirrelator v0.1.0

The first squirrelator release built against the frozen SquirrelGo language
data. It reads that data from **squirrel-lang-data v0.1.0**, the same
release that LanguageStudentDesk and the SquirrelGo apps pin, so all of them
can be tested together on identical data. Fixes found in testing will come
out as v0.1.1, v0.1.2 and so on.

## What's in it

- **Translation that works today**, with nothing new added: English or
  pseudocode to code, code to plain-English explanations, and simple
  code-to-code through English. The targets are Python, JavaScript,
  QuickBASIC, LOLCODE, brainFOOD, Z80, Shell and SQL, plus Latin and
  Klingon. It runs from the desktop window (the default), from the command
  line with `--cli`, or from the web demo in `app/index.html`.
- **The language data from squirrel-lang-data**, pinned as a submodule at
  `data/` to v0.1.0. LanguageStudentDesk can hand squirrelator its own
  checkout through `SQUIRREL_LANG_DATA`, so there's only one copy of the
  data.
- **Golden tests** that record every behavior `translate()` has today, 438
  translations in all, and a check that the generated code actually runs.
  Later releases can change the engine without quietly breaking what works.
- **Checks on every pull request**: tests, ruff, a syntax check of the web
  app, and the PR guard.
- `squirrelator.__version__` now matches the package version.

## Not in this release

The full engine (analyze, parse, interlingua, generate and rank), and
translation between human languages using the shared data, start in v0.2.0.
