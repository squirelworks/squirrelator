# squirrelator v0.1.1

The first release of the squirrelator phone app, and a real translation
engine for human languages. Translate between English, Latin, Klingon and
the other languages in the shared SquirrelGo data, or have code explained
in plain words. Human-language translation is new and marked alpha. It
reads squirrel-lang-data **v0.1.5**, the same release LanguageStudentDesk and
the SquirrelGo apps pin.

## What's new

- **A pipeline for human languages.** Text goes through five stages
  (Analyze, Parse, Interlingua, Generate and Rank) and comes out in any
  language that has a word list or a meaning-matrix column in the data.
  It's marked alpha everywhere.
- **Auto is now the default engine.** Code and the pairs the rules engine
  already handled stay on rules, so their results are unchanged. Sentences
  between English, Latin and Klingon go to the pipeline, and so does any pair
  the rules engine can't handle. Under Auto, Latin and Klingon also show the
  other engine's answer as a second opinion.
- **Latin and Klingon grammar from the data's tables.** Latin nouns,
  adjectives and verbs are declined and conjugated, and they agree in
  person, number, gender and case, prepositional phrases included. With the
  fuller Latin column in data v0.1.5, the verb comes last. Klingon verbs take
  their subject and object prefixes, nouns their plurals and -Daq, and the
  word order is Klingon's own (object, verb, subject). A bare Klingon
  `jatlh` is third person. English verb and noun forms are read too
  ("went", "children").
- **English as the source reads more carefully.** A word with several
  meanings takes the reading the matrix row has (love, house, have).
  Contractions in a row's wording count as its pieces, and English
  contractions come from the data. In spaced languages, a prefix with a
  content meaning heads its own phrase, a prefix may glue to a phrase, and a
  gloss-only phrase doesn't swallow words that have meanings.
- **A bare 今日は** reads as hello, the same as こんにちは. In a longer
  sentence it still means "today".
- **Explaining code in more languages.** Code explanations use the code
  pack's English sentences ("Print the word.", with the quoted string on the
  next line), then the pipeline can put that into any language that has a
  column. Code-to-code still uses the literal.
- **Data v0.1.5.** French, German and Italian meaning-matrix columns, and
  Latin, Greek and Russian filled to every row. Klingon *Qapla'* is Latin
  *Fēlīciter!*
- **Chinese and Klingon matrix misses closed** for the known leftovers
  (吃饭, 几点了, jIyajbe'). Under Auto, conjugated Klingon like `Dajatlh'a'`
  stays on the Pipeline (`You speak?`) instead of the Rules print pattern.
  A coverage report of every meaning-matrix column runs in CI, and Pipeline
  pair alpha drops when a column clears the bar. A regression report also
  runs in CI: golden translations always, and pair accepts from the pinned
  data under `testing/translation-pairs/` when that folder exists.
- **French `est-il` and dual-meaning markers.** Hyphenated words match
  matrix wording that folds hyphens to spaces (`Quelle heure est-il ?` →
  `What time is it?`). A word that is both content and a marker (Thai
  `อยู่`) only acts as a marker next to the neighbours the column wrote.
- **Phase 3 twin translate UI.** Two panes with per-side language pickers
  and swap, Alternatives and Breakdown under Result, unknown-word
  highlighting and an alpha badge, and sentence-by-sentence translate for
  pasted prose — matching in the Tk window and the web app.
- **Phase 4 intent grammar (start).** English instructions for print,
  loops, assignment, `if` / `if … else`, input, function-that-prints,
  lists and maps parse into a structured Intent, then generate code. The
  golden Rules outputs are unchanged.
- **The desktop window** has Auto in its Engine menu and shows the second
  opinion. The pipeline can also be picked on its own.
- **The phone app's first release.** One Compose translate screen for
  Android and the desktop (`native/`), with Auto and the second opinion like
  the desktop window. When this release is published, it goes to Google
  Play internal testing.
- `translate_full()` returns the translation with its alternatives, a
  step-by-step breakdown, unknown words and a confidence score.

## Changed results

The golden tests record every output. Since v0.1.0 these Latin and Klingon
sentences that Auto now sends to the pipeline have changed:

- "sort the list", English to Latin: *Indicem ōrdinā.* (v0.1.0 couldn't
  match it).
- `Qapla'`, Klingon to English: *Success!* (v0.1.0 only repeated the
  statement). Klingon to Latin: *Fēlīciter!*
- `jatlh "nuqneH"`, Klingon to Latin: *Salvē loquitur.* (v0.1.0 couldn't
  match it; an earlier draft of these notes had first-person *Loquor
  salvē.*)

## Not in this release

- Klingon still has no code-pack column, so explaining code in Klingon
  stays on the older wording.
- Pipeline pair alpha labels follow the CI coverage bar (≥90% of
  meaning-matrix rows top-1 both ways). Free-sentence test sets are still
  ahead.
