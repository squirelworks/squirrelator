# squirrelator v0.1.1

The first release of the squirrelator phone app, and a real translation
engine for human languages. Translate between English, Latin, Klingon and
the other languages in the shared SquirrelGo data, or have code explained
in plain words. Human-language translation is new and marked alpha. It
reads squirrel-lang-data v0.1.4, the same release LanguageStudentDesk and
the SquirrelGo apps pin.

## What's new

- **A pipeline for human languages.** Text goes through five stages
  (Analyze, Parse, Interlingua, Generate and Rank) and comes out in any
  language that has a word list or a meaning-matrix column in the data.
  It's marked alpha everywhere.
- **Auto is now the default engine.** Code and the pairs the rules engine
  already handled stay on rules, so their results are unchanged. Sentences
  between English, Latin and Klingon go to the pipeline, and so does any pair
  the rules engine can't handle. Under Auto, Latin and Klingon also show the
  other engine's answer as a second opinion.
- **Latin and Klingon grammar from the data's tables.** Latin nouns,
  adjectives and verbs are declined and conjugated, and they agree in
  person, number, gender and case, prepositional phrases included. Klingon
  verbs take their subject and object prefixes, nouns their plurals and
  -Daq, and the word order is Klingon's own (object, verb, subject).
  English verb and noun forms are read too ("went", "children").
- **Explaining code in more languages.** The data's code pack ("Print the
  word.", "Count from one to ten.") can be read and written in Japanese,
  Chinese, Korean, Latin and ten other columns.
- **The desktop window** has Auto in its Engine menu and shows the second
  opinion. The pipeline can also be picked on its own.
- **The phone app's first release.** One Compose translate screen for
  Android and the desktop (`native/`), with Auto and the second opinion like
  the desktop window. When this release is published, it goes to Google
  Play internal testing.
- `translate_full()` returns the translation with its alternatives, a
  step-by-step breakdown, unknown words and a confidence score.

## Changed results

The golden tests record all 438 outputs, and since v0.1.0 three of them have
changed, all of them Latin or Klingon sentences that Auto now sends to the
pipeline:

- "sort the list", English to Latin: *Indicem ōrdinā.* (v0.1.0 couldn't
  match it).
- `Qapla'`, Klingon to English: *Success!* (v0.1.0 only repeated the
  statement).
- `jatlh "nuqneH"`, Klingon to Latin: *Loquor salvē.* (v0.1.0 couldn't
  match it). It should be *Loquitur*, since a bare `jatlh` is third person.
  That fix will come in a later release.

## Not in this release

- Explanations of code that use the code pack's English exactly (squirrel-lang-data
  #56). The rules engine still writes its own wording, such as `Print "hi"`.
